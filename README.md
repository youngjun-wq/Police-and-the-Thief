# 제 8회 보드방정 정모 '대현산 추격전' 🚨

대현산 배수지공원에서 펼쳐지는 경찰과 도둑 야외 추격전 공식 모바일 가이드입니다.

## 📅 행사 정보
- **일시:** 2026년 11월 14일 (토) 16:00
- **장소:** 대현산 배수지공원 (관리사무소 앞 광장)
- **참가비:** 인당 10,000원 (실물 만보기 기기, 손가락 막대기 등 게임 소모품)
- **규모:** 정영준(방장), 김준형(부방장), 기명찬(실장), 심완기(감옥지기), 권성환(작가), 최은혜(영양사), 이준수(비서) + 스페셜 게스트

## ⏱️ 식순
1. **16:00 ~ 17:00 (60분):** 공원 집결, 게임 범위 답사, 룰 & 안전수칙 브리핑, 실물 만보기 장착 및 팀 편성
2. **17:00 ~ 17:50 (50분):** 🚨 본격 '경찰과 도둑' 추격전 메인 이벤트
3. **17:50 ~ 18:00 (10분):** 실물 만보기 걸음수 정산, 결과 발표, 기념사진 촬영
4. **18:00 ~ :** 인근 치맥집 이동 후 뒤풀이 (자율 참석)

## 📌 주요 규칙
- **경찰:** 손가락 막대기로 신체 찔러 체포 (신체 접촉 금지)
- **도둑:** 실물 만보기 평균 3,500보 이하 제한 미션, 감옥 동료 구출 도전
- **감옥지기(심완기):** 체포 도둑 관리 및 구출 퀴즈 출제·판정
- **구출 규칙:** 퀴즈 정답 시 갇힌 도둑 **전원 즉시 구출(대탈출)**, 탈출 시 만보기 0보 리셋 (오답 시 1분 쿨타임)
- **긴급 구호:** "중지!" 또는 "타임!" 외치면 전원 즉시 정지
